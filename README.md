# Сайлент-Лобня
Оригинальный шуточный путеводитель о вымышленной хоррор-версии города Лобня. Статический сайт без сборки и npm-зависимостей.

## Запуск
Из каталога репозитория: `python3 -m http.server 8000 --bind 0.0.0.0`.

Откройте сайт в браузере. Карточки мест и записи архива открывают диалоговые окна; радио включает тихий синтезированный шум только после нажатия. Escape закрывает документ. Поддерживаются мобильные экраны и reduced motion.

Шрифты Caveat, Manrope и Oswald загружаются из Google Fonts; при недоступности сети используются системные. Иллюстрации сделаны в SVG и CSS, звук генерируется Web Audio API. Заимствованных игровых материалов нет. Проект не связан с Konami.
